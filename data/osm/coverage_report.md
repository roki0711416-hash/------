## 補完戦略（提案）

### 1. 住所欠損の補完（逆ジオコーディング）

unmapped（都道府県不明）のレコードは lat/lng を持っているため、
逆ジオコーディング（Nominatim等）で都道府県を推定できます。

```
# 例: Nominatim reverse
GET https://nominatim.openstreetmap.org/reverse?lat={lat}&lon={lng}&format=json
→ address.province に都道府県が入る
```

### 2. タグ取りこぼし対策

現在のクエリは `leisure=adult_gaming_centre` と `gambling=pachinko` を取得しています。
追加で以下のタグも検討してください：

- `amenity=gambling`
- `shop=gambling` + name にパチンコ関連語を含むもの
- `gambling=slot_machines`（スロット専門店）

### 3. ユーザー投稿 / 運営手動追加

CSVインポーター（`scripts/importStoresCsv.ts`）が既に存在するため、
低カバレッジ県のデータは手動CSV追記で補完できます。

```bash
# data/stores_master.csv に行を追加して再投入
npx tsx scripts/importStoresCsv.ts
```

### 4. データソース分散

許諾の取れる公開データ（例: 各都道府県の営業許可リスト）を
見つけた県から順に追加していく戦略も有効です。
各県の公安委員会が公表しているパチンコ営業許可リストを確認してください。
